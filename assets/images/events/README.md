# Event collaborator images

Photos or logos for the collaborators shown on the **Events** page.

Save each image in this folder using the file name listed in the
`COLLABORATORS` list at the top of `js/events.js` (for example
`paola-rojas.jpg`). A square image, roughly 400x400px, looks best (JPG, PNG or
WebP). Until a file is added, the page shows the person's initials instead,
so it always looks finished.
